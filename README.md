# TripSplit

แอปหารเงินทริปและค่าข้าวแบบส่วนตัว ใช้บนมือถือ ทำงานออฟไลน์ ข้อมูลอยู่ในเครื่องเท่านั้น (ไม่มีเซิร์ฟเวอร์)

- หลายสกุลเงิน: เรตกลางต่อทริป + แก้เป็นยอดบาทจริงรายบิล
- หารเท่ากัน / ระบุจำนวน / ทีละจาน (+ Service charge, VAT)
- หลายคนจ่ายต่อบิล, สรุปโอนน้อยครั้งที่สุด, คัดลอกไปวางไลน์
- สำรอง/กู้คืนเป็นไฟล์ JSON

**ใช้งาน:** เปิด https://yutthapob-ja.github.io/tripsplit/ ใน Safari → แชร์ → “เพิ่มไปยังหน้าจอโฮม”

## พัฒนา
```bash
npm test          # ทดสอบ (node --test)
npm run bump      # ต้องรันทุกครั้งที่แก้ไฟล์แอป — อัปเดต VERSION ใน sw.js ให้มือถือรู้ว่ามีเวอร์ชันใหม่
```
อัปเดตเว็บ: แก้โค้ด → `npm run bump` → `npm test` → commit → `git push` (GitHub Pages อัปเดตเองภายในไม่กี่นาที)

> สำคัญ: อย่าเปลี่ยนชื่อ repo/ที่อยู่เว็บ — ข้อมูลในมือถือผูกกับที่อยู่เว็บนี้
